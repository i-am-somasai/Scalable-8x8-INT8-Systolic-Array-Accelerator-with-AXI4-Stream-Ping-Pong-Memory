# Toolchain

This project relies on a modern, open-source VLSI toolchain. 

## Software Dependencies

| Tool | Purpose | Status |
|---|---|---|
| **Python 3** | General scripting and orchestration. | Required |
| **NumPy** | High-performance matrix mathematics used to construct the Golden Reference Model. | Required |
| **Icarus Verilog (`iverilog`)** | The primary RTL simulator. Compiles the SystemVerilog codebase and executes the testbench. | Required |
| **GTKWave** | Waveform viewer used to inspect the `.vcd` dumps generated by Icarus Verilog. | Optional |
| **Verilator** | High-performance C++ simulator and strict Linter. Used in this project specifically for executing SystemVerilog Assertions (SVAs) and collecting Functional Coverage, which Icarus does not support. | Optional |
| **Make** | Automates the execution of Python, Icarus, and comparison scripts. | Required |

## Physical Design (ASIC Flow) Tools

These tools are part of the OpenROAD/OpenLane ecosystem. They are only required if you intend to push the RTL through to physical layout (GDSII).

| Tool | Purpose | Status |
|---|---|---|
| **Yosys** | Open-source logic synthesis. Maps the behavioral RTL to standard cells. | Optional |
| **ABC** | Runs inside Yosys to perform technology mapping and gate-level optimization. | Optional |
| **OpenSTA** | Static Timing Analysis engine. Verifies setup, hold, and maximum clock frequencies against `constraints.sdc`. | Optional |
| **OpenROAD** | The core physical design application. Handles Floorplanning, Placement, Clock Tree Synthesis (CTS), and Global/Detailed Routing. | Optional |
| **SKY130 PDK** | The SkyWater 130nm Process Design Kit. Provides the physical cell libraries (`.lib`, `.lef`) required by the physical design tools to calculate actual area, power, and delay. | Optional |
